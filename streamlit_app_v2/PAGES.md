# Alternative presentation structure

The narrative asks one question: can a model be right for the wrong reason?

| # | Page | Primary focus |
| --- | --- | --- |
| - | Opening | Trust question and headline scale |
| 1 | The question | Prediction versus evidence |
| 2 | The material | Class balance and multi-source data |
| 3 | The audit | Duplicate, encoding, and intensity warnings |
| 4 | The controls | Reproducible preprocessing and frozen split |
| 5 | The floor | Classical baseline comparison |
| 6 | From scratch | CNN capacity and image-region comparison |
| 7 | Borrowed vision | Transfer-learning experiments |
| 8 | The suspicion | Grad-CAM and lung-focus evidence |
| 9 | The causal test | Background masking intervention |
| 10 | What survives | Background, texture, and shape decomposition |
| 11 | The boundary | Validation requirements |
| 12 | The verdict | Scientific conclusion |
| 13 | Live classifier | Real inference on an uploaded X-ray |

Evidence screens show a single dominant figure. Secondary figures sit behind tabs. Desktop layouts use dynamic viewport height units and bounded `clamp()` sizing; mobile layouts return to natural document flow and scrolling.
